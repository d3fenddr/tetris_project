# Web Mini App (Scaffold)

This folder contains the Telegram Mini App frontend scaffold (`React + TypeScript + Canvas`).

## Run
```bash
cd webapp
npm install
npm run dev
```

## Notes
- This is a migration scaffold, not the final gameplay-complete web Tetris.
- Mobile-friendly vertical layout targets roughly `350x700`.
- Includes touch controls + keyboard hooks.
- Telegram launch and score submission should call backend endpoints once wired.
